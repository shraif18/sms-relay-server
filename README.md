# SMS Forwarder

אפליקציית Android שמעבירה קודי התחברות (SMS) ל-CRM של הסוכן, לצורך מילוי
אוטומטי בתוסף הכניסה לפורטלים.

כל סוכן מעביר רק את הקודים של עצמו, לטלפון שלו, ל-CRM שלו. הקוד נשמר ב-CRM
משויך לאותו סוכן בלבד, והתוסף שלו מושך אותו.

## בנייה (GitHub Actions)

כל push ל-`main` / `feat/**` / `test/**` בונה APK חתום (release). ב-GitHub:
Actions ← הריצה האחרונה ← Artifacts ← **otp-relay-apk**.

הבנייה דורשת שני Secrets בריפו (Settings ← Secrets and variables ← Actions):
`SIGNING_KEYSTORE_BASE64`, `SIGNING_STORE_PASSWORD`. **כל גרסה חייבת להיחתם באותו
מפתח** — אחרת לא ניתן לעדכן אפליקציה מותקנת. המפתח שמור מחוץ לריפו ואסור להעלות
אותו ל-git.

## התקנה בטלפון

1. להעביר את קובץ ה-APK לטלפון ולפתוח אותו (לאשר "התקנה ממקורות לא ידועים").
2. לתת לאפליקציה הרשאות SMS. אם אנדרואיד חוסם ("הגדרה מוגבלת"): הגדרות ←
   אפליקציות ← **העברת קודי כניסה** ← ⋮ ← **אפשר הגדרות מוגבלות**, ואז לאשר.
3. גרסה ישנה בשם "SMS Forwarder" אפשר להסיר — זו אפליקציה נפרדת.

## חיבור ל-CRM

ב-CRM: הגדרות ← **תוסף כניסה לפורטלים** ← **חיבור מכשיר** ← **צור קוד חיבור**.
אז באפליקציה:

- הדבק את **קוד החיבור** (JSON) בשדה העליון, או
- מלא ידנית **כתובת ה-CRM** ו**טוקן המכשיר**,

ולחץ **שמור הגדרות**. אפשר ללחוץ **שלח קוד בדיקה** כדי לוודא שהחיבור עובד.

## שימוש

כשמגיע SMS עם קוד התחברות, הוא מועבר אוטומטית ל-CRM, והתוסף בדפדפן ממלא אותו.
האפליקציה מעבירה רק הודעות שמכילות קוד; הודעות אחרות לא נשלחות.

> הערה: אין צורך להפוך את האפליקציה לאפליקציית ה-SMS הראשית — היא מאזינה לקודים
> ברקע דרך הרשאת `RECEIVE_SMS`.
